## ④ 실측 차이표 — 원인은 하나
`font:var(--fw-b) var(--fs-label) inherit` 축약형은 **무효**다(`inherit`은 축약 안에서 family가 못 된다). 무효 선언은 longhand가 전부 상속으로 떨어져 **body 15px/400**을 물려받는다. sb:71 주석이 같은 진단을 이미 남겼다("축약이 무효화돼 15px 상속되던 것 교정").

| 파일:행 | 선택자 | 선언 | 실제 렌더 |
|---|---|---|---|
| index:2997, thumb:385, tr:111 | 라벨 `.pub-l`/`.nm` | 분해 | 13px/700 |
| index:3070, thumb:51, tr:113, k:140 | 칩 | 무효 축약 | **15px/400** ⚠ |
| index:3072 | `.geni-opt.on` | `font-weight:var(--fw-x)` | 800(켠 칩만) |
| thumb:382, tr:117 | 토글·수치 | `font-size:var(--fs-label)` | 13px |
| sb:71 | `.geni-opt` | family+size+weight 분해 | **13px/700** ✅ 정본 |

한 카드 안에서 라벨 13/700, 칩 15/400, 켠 칩 15/800이 따로 논다.

토큰(`--fs-label:13`·`--fw-b:700`·`--fw-x:800`)은 index:73–74 정본이 `tokens.css`로 4탭에 공급돼 **값은 이미 같다.** body family도 4탭 동일(Pretendard Variable 6패밀리 + `-.2px`). `@font-face`만 갈린다 — thumb·tr만 **Noto Sans KR 400/700** 추가 보유(스코프 = 카드 캔버스, UI 무접촉). **원인은 폰트 자산이 아니라 무효 축약 4곳뿐.**
