## 5. 캐시 / Service Worker 리스크 (별개 원인 점검)

- **thumb.html은 캐시로 구버전이 남을 수 없다**: ① `viewer/_headers` `/thumb`·`/thumb.html Cache-Control: no-cache` ② index의 loadToolFrame이 `?v=Date.now()` 버스트 ③ `sw.js` `SHELL_PATHS = ['/', '/index.html']` 화이트리스트 밖(주석 정본: 도구 HTML은 "절대 캐시 대상 아님").
- **index.html 셸은 1방문 지연 가능**: `SHELL_CACHE 'nm-shell-v1'` stale-while-revalidate — 배포 직후 첫 진입은 직전판 셸을 서빙하고 백그라운드 갱신 후 `nm-shell-updated` 토스트. 코너 레일이 향후 **index 쪽(AI 생성 리드 `.geni-prev .cpprev-box`·모달 크롬)** 에 배선되면 운영자 화면 반영이 한 방문 늦는 별개 원인이 된다(탈출구 `?nosw=1`). 이번 건의 원인은 아님(§4).

## 7. 「모든 화면 적용 시」 버그 요소 (사전 발굴)

1. **팝 잘림**: `.cpprev-box{overflow:hidden; container-type:size; contain:size}` — 레일 펼침팝을 미리보기 안 앵커로 두면 박스 경계에서 잘린다. 밖으로 빼면 스태킹(z) 재설계.
2. **글래스 blur 무효**: `.topdock` mat 불투명 + 순흑 스테이지 위 backdrop-filter 시각효과 0 — thumb 293행 실측 주석·#3470 커밋 메시지 실측 동일 결론. 10안 1안(셀렉터 합류) 값 그대로는 blur가 안 보임 → thumb 번역(.scard 면·선) 필요.
3. **편집 탭 이중 내비**: 편집(7·8·9)은 이미 `#editCol` 우측 세로 옵션 컬럼(2분할) — 코너 레일 병존 시 옵션 SSOT 2벌.
4. **dockmin 축소 추종**: 스크롤 시 편집 미리보기 폭 52%(#3462) — 코너 앵커 레일이 같이 축소·이동, 히트타깃 붕괴.
5. **1:1 + 캡 해제의 화면 잠식**: #3462 커밋 자인 — 낮은 창 조합 35%에서 도크>iframe 높이. 레일이 코너 추종이면 화면 밖 이탈.
6. **미러 표면 전파 누락**: iframe 자기완결 사본 규칙상 thumb 외에 index `#genidlg` AI 생성 리드(#3462가 이미 1:1 동조), `tr.html` 상단 도크(thumb 카드 생성 정본 이식), song/nb/sb 형제까지 동반 배선 없으면 파리티(smoke_parity C1·C10) 깨짐.
7. **OPA 제스처 충돌**: `.gs-opav` 휠/상하드래그(ns-resize)·`touch-action:pan-y` 계약 — 세로 레일 캡슐 안에서는 페이지 스크롤·스와이프와 정면 충돌(모바일 ± 스테퍼 대체 필요).
8. **클래스 재사용 함정**: 본문 `.trail/.trailwrap`은 `position:fixed`(뷰포트 기준)·z=34 — 모달 내 미리보기 코너에는 그대로 못 쓴다(absolute 재배선 필수 · 셀렉터 충돌).
9. **스트립 삭제 후 리듬 붕괴**: `.dockgrid` 하단 간격이 구 스트립 여백에 의존했던 이력(473행 주석) — 삭제 시 미리보기↔생성 간격 재확인 필요.
10. **상태·핸들러 이주**: 위 표의 id 전부가 핸들러 정본(cOpaSel·ovOnly 등 상태 1벌) — DOM만 지우면 JS 참조 에러. 삭제가 아니라 「레일로 이주」로 설계해야 함.

미확인: 운영자 실기기(라이브 apps.nomute.kr)의 배포 리비전 — 이 환경에서 원격 실기기 화면은 관측 불가. 단 §4에 의해 어느 리비전이든 레일은 없다(배선 커밋 부재).
