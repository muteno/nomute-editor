영상 스튜디오 세부탭 전환 “번쩍” — 전/후 프레임 증빙

측정 = 헤드리스 CDP 스크린캐스트(412×915 · DOM 무접촉 · 라이브 코드 그대로). 장면 = 이미 방문한 탭으로 되돌아오기(편집 → 자막 → 콘티 → 편집). 클릭 시각 = 0ms.

전(before) 클릭 → 빈 판 2프레임(≈100ms) → 통째 재로딩된 화면

+82ms·+147ms 두 프레임이 11KB(= 콘텐츠 없는 판). 원인 = 탭 클릭이 loadToolFrame() → 같은 iframe에 ?v=Date.now() 캐시버스트로 다른 문서를 통째 재로딩 + 그 동안 .ready를 벗겨 프레임을 투명(opacity 0)으로 만드는 은폐 구간.

후(after) 클릭 → 첫 프레임부터 완성 화면(빈 판 0장)

탭마다 전용 iframe을 숨김-보존(번역 탭 정본 문법 그대로) → 재방문 = 리로드 0 · 동기 재레이아웃 뒤 ‘스냅’ 노출이라 빈 판이 낄 프레임 자체가 없다. 입력한 폼·첨부한 영상도 탭을 오가도 그대로 남는다.

계측 요약

클릭전 — 빈 판 프레임후 — 빈 판 프레임
자막(첫 방문)2장 (≈100ms)1장 (최초 로드 = 불가피)
콘티(첫 방문)1장1장 (최초 로드 = 불가피)

즉 최초 1회 로드만 남고, 이후 탭 왕복은 번쩍이 구조적으로 불가능해진다.
