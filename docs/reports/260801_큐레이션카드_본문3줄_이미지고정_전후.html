운영자 260801: “항상 3줄까지는 나오게 하고, 만약 1줄이면 2줄은 공백” + “이미지는 항상 일정한 공간에 나오게 · 네모 틀은 유지”. 본문(.xcard-tx.s2)이 글 길이에 따라 1~5줄로 널뛰면서, 바로 아래 대표 이미지(.xcard-cv)의 시작 y가 카드마다 달라지던 것을 봉합. 네모 틀(16:9 · --r-s 라운드 · 크롭 문법)은 그대로.

층내용
전[data-sec=sx] .xcard-tx.s2 { -webkit-line-clamp:5; min-height:0; }

후.xcard-tx.s2 { -webkit-line-clamp:3; height:calc(3 * 1.5em); } — 단일 정본
핵심min-height(하한) → height(고정). 하한이라 1줄 글은 1줄 높이 그대로였고, 그만큼 이미지가 위로 올라붙었다. 고정 예약이면 1줄 글도 3줄 자리를 차지 = “2줄은 공백”.
산식3 * 1.5em = 자기 line-height 동원(px 하드코딩 0 · .tcard-t·.rt2col 문법 계승 · 신규 토큰 0)
스코프큐레이션 게시물 카드 공용 = X(sx) · 스레드(sth) 동일(§0-3 같은 기능 = 같은 모양). 구 X 전용 5줄 분기(260727)는 이 단일 계약에 흡수 — X가 스레드보다 2줄 길던 비대칭도 함께 해소.
무접촉이미지 틀(16:9 · --r-s · object-fit:cover) · 메타행 바닥 고정(margin-top:auto) · 카드 높이 동기(xgrid stretch) · .rt2col 5줄 분기(별개 유닛)

한계(정직)

  • 3줄 넘는 원문은 3줄 + …로 잘린다(구 X 5줄 → 3줄 = 2줄분 축약). 전문은 카드 클릭 = 인앱 임베드로 종전대로.
  • 대표 이미지가 없는 게시물은 종전대로 이미지 자리를 만들지 않는다(‘조용한 공백’ 정책 유지) — 남는 높이는 그리드 stretch가 흡수해 메타행·카드 바닥은 계속 일렬.
  • 캡처의 색면은 실사진이 아니라 합성 플레이스홀더(pbs.twimg 핫링크를 캡처 런에서 로컬 PNG로 치환) — 검증 대상이 기하(자리·크기)라 사진 내용은 무관.
  • shared/smoke_ghead.js는 이 변경 전·후 동일하게 1건 FAIL(금융 tg-fin 헤더 = 라이브 데이터 결측 MISS) — 이 카드 표면과 무관한 선재 red.
