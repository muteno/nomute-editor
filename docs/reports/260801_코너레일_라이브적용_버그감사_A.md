## 4. 레일 자체의 구조 리스크(드리프트)

- `.trail` 계열 CSS는 **index.html 인라인 전용**(`viewer/index.html:1196~1206`) — thumb/tr/conv 등은 **별도 iframe/단독 문서라 상속 불가**. `viewer/tokens.css`에 `trail` 0건(직접 grep).
- 시안(`docs/reports/260801_미리보기코너옵션_플레이그라운드.html:119` 등)도 사본으로 갖고 있음 = 사본 배포 방식이면 표면 수(최대 10)만큼 드리프트원.
- **처방(근거 있는 순)**: ① `.trail` 블록을 `viewer/tokens.css`로 승격 — 전 표면이 이미 로드(`thumb.html:9`·`tr.html:9` `<link rel="stylesheet" href="tokens.css">`)하고, `--press-*` 사다리 승격 선례(`thumb.html:21` "tokens.css 상속·인라인 이중정의 제거·감사 260704") 존재. 단 tokens.css는 "색 제외 구조토큰" 규약이라 `.trail`의 글래스 색(rgba(8,15,11,.34))을 넣으려면 규약 개정 or 색만 표면 오버라이드. ② 사본+게이트라면 check_refs에 「.trail 사본 동일성 게이트」 신설(도크 규격 게이트 선례 :1582 동문). ①이 정본.
- index쪽 `.trail`은 `.trailwrap`(z34·좌측 고정) 배치 전제 — 미리보기 코너용은 배치 규칙이 다르므로 **컴포넌트(필·아이템)와 배치(wrap)를 분리 편입**해야 SNS 레일 회귀가 없다(CII :56 행 개정 동반).

## 6. 포맷별 깨짐(1:1 창 × 9:16/4:5/1:1 스테이지) — CSS 기하 산술

- 스테이지 = `left:50%;translateX(-50%); height:100%; width:auto; aspect-ratio 9/16 | 4/5`(:355·362·363) · 창 = 폭 W의 1:1(:480).
- 산술(도크 전폭 W=566px 기준·:472 실측 주석값):
  - **9:16**: 스테이지 폭 = 0.5625W ≈ 318px → 좌우 필러 각 ≈ **124px**. 우상단 레일(여백 0)은 콘텐츠에서 ~124px 떨어진 **순검정 필러(#121212) 위에 부유** — 바탕알파 .54 글래스는 배경 변화가 없어 블러 무의미(§🎨 h backdrop-filter 축과 동일 결론), "떠 있는 알약"만 남는다.
  - **4:5**: 필러 각 0.1W ≈ 57px — 동일 문제 약화판.
  - **1:1**: 필러 0 — 레일이 **사진 위에 직접 얹힘** → 알파 .54가 사진을 가리고, 밝은 사진에서 대비 미달 가능.
  - → 같은 여백 0 지시가 포맷에 따라 「콘텐츠에서 멂 ↔ 콘텐츠 가림」 3종으로 갈라짐. 앵커를 박스가 아닌 **스테이지(.cpprev-stage)** 기준으로 할지 운영자 결정 필요.
- 실렌더 스크린샷 대조 = **미확인**(산술은 CSS 선언만으로 확정).

## 7. 접근성·모바일·기틀 값

- 22px 아이템 + 히트패드 = 실효 34×30 — CII :56에 이미 "평의회② 22px=기준 50% 지적" 이력. 44px 권고 미달 + §5 클리핑으로 더 축소. 실기기 탭 성공률 = **미확인**.
