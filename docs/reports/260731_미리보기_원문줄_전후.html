③ 원인 — 한 줄이 두 증상을 만들었다

범인 = viewer/edit.html:163 .pvsub span { display:block; }
저자 스타일시트의 이 규칙이 hidden 속성의 UA 기본값 display:none을 이긴다. 그래서 pvSync가 「한글만」·「자동」에서 tl.hidden = true로 정확히 꺼놨는데도 화면엔 그대로 남았다. 컨테이너용 .pvsub[hidden]{display:none}(241행)은 있었지만 자식 span 짝이 없었다.

그리고 같은 한 줄이 “영문이 굉장히 크다”도 만들었다. hidden 분기에서는 pvSync가 인라인 font-size(한국어 × 50%)를 안 먹인다 — 숨긴 줄이라 계산할 이유가 없으니까. 그래서 CSS 폴백 .pvsub .pvsub-tr{font-size:.5em}만 남는데, 이 em은 부모(.pvsub, 상속 15px) 기준이라 7.5px 고정이 된다. 한국어 줄은 캔버스 비례로 9.24px까지 줄었으니 결과가 81% — 두 증상이 하나의 뿌리다.

처방 = .pvsub span[hidden] { display:none; } 한 줄(명시도 0,2,1 > 0,1,1). dual 경로는 hidden=false라 종전 그대로 = 회귀 0(위 3번째 카드에서 50% 실측 확인).
