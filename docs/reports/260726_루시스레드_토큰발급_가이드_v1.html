⚠ 시작 전에 — 로그인 계정이 제일 헷갈리는 지점이다

이 작업엔 계정이 2개 나온다. 섞이면 전부 실패한다.

어디서어느 계정으로
Meta 개발자 콘솔
(앱·권한·토큰)		본계 — 기존 nomute-insights 앱 주인
테스터 초대 수락
(스레드 앱/웹)		부계(루시)

즉 앱은 본계가 만들고, 루시 계정은 "이 앱이 내 계정 써도 돼"라고 수락만 한다.

준비물 (먼저 끝내둘 것)

  • 루시 인스타 부계 — 프로페셔널(크리에이터 or 비즈니스) 전환 필요
  • 그 계정으로 스레드 가입 완료 — 스레드 계정은 API로 못 만든다, 앱에서 수동 가입만

1단계 — 앱에 Threads 켜기 (본계)

개발자 콘솔 열기

브라우저에서 본계로 로그인된 상태인지 먼저 확인. 다른 계정이면 로그아웃하고 본계로 다시.

내 앱 목록 열기 ↗

목록에 nomute-insights가 보여야 정상.

앱 선택 → 유스케이스 추가

nomute-insights 클릭 → 좌측 메뉴에서 사용 사례(Use cases) → 사용 사례 추가.

앱 ID 복사1522670392977528

목록에서 Threads API 액세스를 고른다.

목록에 Threads가 안 보이면?

이 앱은 인스타/페북용으로 만들어져서 Threads 추가가 막혀 있을 수 있다. 그러면 앱을 새로 하나 만들면 된다 — 아래 3단계부터 절차는 완전히 동일하다. 기존 앱은 그대로 두고 건드리지 마라(채널요약 수집이 돌고 있다).

새 앱 만들기 ↗

유형은 비즈니스, 이름은 자유(예: lucy-threads).

권한 4개 체크

Threads 설정 화면에서 아래 4개를 전부 켠다. 하나라도 빠지면 그 기능이 통째로 죽는다.

1 복사threads_basic
2 글쓰기 복사threads_content_publish
3 답글읽기 복사threads_read_replies
4 답글쓰기 복사threads_manage_replies

2번이 없으면 글을 못 올리고, 3·4번이 없으면 자동 댓글이 안 된다.

2단계 — 루시 계정을 테스터로 (본계 → 부계)

초대 보내기 (본계)

앱 대시보드 → 앱 역할(App roles) → 역할 → 사람 추가 → 역할 = Threads 테스터 → 루시 계정 사용자명 입력.

역할 화면 바로가기 ↗

새 앱을 만들었다면 위 링크의 숫자를 새 앱 ID로 바꿔서 들어간다.

수락하기 (부계 — 여기서 계정 바꾼다)

루시 계정으로 스레드 앱 로그인 → 설정 → 계정 → 웹사이트 권한 → 초대에서 수락.

스레드 계정 설정 ↗

인스타 쪽 경로로도 뜬다:

인스타 테스터 초대함 ↗
여기서 제일 많이 막힌다

「개발자 역할 권한 부족」이 뜨면 — 브라우저가 본계로 로그인된 상태인 거다. 스레드/인스타에서 루시 계정으로 전환하고 다시 시도. (실측된 함정 · 인스타 세팅 문서 §8-1)

3단계 — 토큰 받기 (본계)

토큰 생성

개발자 콘솔로 돌아와 Threads 설정 화면 → 액세스 토큰 생성(Generate access token) → 팝업에서 루시 계정 선택 → 권한 동의.

순서 중요 — 수락 먼저, 토큰은 그 다음

2단계 수락 전에 만든 토큰은 옛 권한이라 안 붙는다. 이미 만들었으면 버리고 다시 만들어라.

화면에 뜨는 긴 문자열이 토큰이다. 이게 60일짜리다.

토큰이 맞는지 1초 검산

이런 모양이어야 한다 — TH로 시작하고 아주 길다.

짧거나 EAA로 시작하면 그건 페이스북 토큰이지 스레드 토큰이 아니다. 다시 받아라.

4단계 — GitHub에 넣기

토큰 등록 (Secret)

시크릿 등록 화면 ↗

New repository secret → 이름은 아래 그대로, 값은 3단계 토큰.

이름 복사THREADS_ACCESS_TOKEN
토큰은 여기 말고 어디에도 붙이지 마라

채팅·메모·커밋 전부 금지. 이 칸은 한 번 저장하면 아무도 다시 못 본다 — 그게 정상이다.

전원 켜기 (Variable)

변수 등록 화면 ↗

New repository variable → 이름 LUCY_ON / 값 1.

이름 복사LUCY_ON

끄고 싶으면 언제든 값만 0으로. 그 순간부터 안 돈다.

루시 카드 넣기

YETA 루시 카드 원문을 persona/lucy_threads.md에 통째로 붙인다. 이게 없으면 러너가 말을 안 한다(말투를 지어내면 루시가 아니니까 일부러 막아뒀다).

✅ 첫 가동 — 반드시 이 순서로

  • ① 드라이런 — Actions → lucy-threads → Run workflow → dry_run 체크 → 실행.
    실제로 안 올리고 "이런 글이 나갔을 것"만 로그로 보여준다.
  • ② 말투 확인 — 로그 읽어보고 어색하면 카드 고치고 ① 반복. 계정 위험 0.
  • ③ 실전 1회 — dry_run 체크 풀고 slot = post로 한 번만.
  • ④ 자동 전환 — 잘 나가면 그냥 두면 된다. 밤 23:00 / 새벽 01:30에 알아서 돈다.
워크플로 실행 화면 ↗
60일마다 토큰 갈아야 한다

스레드 토큰은 60일짜리다. 만료되면 Actions가 빨간 실패로 토큰 만료·무효(code 190)를 띄운다. 그때 3단계만 다시 하고 시크릿 값만 교체하면 된다(2분).
