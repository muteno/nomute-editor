## 1. 운영자 요구 (원문 축약)

1. 진행 안 한 공연을 **점선 네모 테두리**로 감싸던 표기를 폐기.
   → **팔린 만큼만 실선 · 예상되는 만큼만 점선** — 단, 막대가 네모가 아니라
   **게이지처럼 올라가는 단일 선**이므로 «선 자체»를 다르게 그린다.
2. (2차) 점선이 세로로만 끊길 이유 없음 · **불투명 말고 50% + 촘촘하지 말 것**.
3. (3차) 「이게 최선이냐 · 인터넷 사례를 찾아와라」 → 실사례 조사 후 재제안.
4. **확정 = 「페이드 그라데이션」** (실사례 9안 중 3번).
5. (4차) **Y축 중략(물결 ~)이 빠져서 거인/난쟁이 차트가 됐다 — 해결.**

## 2. 확정된 것

| 축 | 확정값 | 근거 |
|---|---|---|
| 예상 구간 표기 | **페이드 그라데이션** (위 0.08 → 아래 0.85, 같은 색) | Stephanie Evergreen «Fade it» — 예상 데이터는 옅은 같은 색이 1순위. 패턴필·점선은 얇은 게이지에서 깨진다 |
| 실판매 구간 | 불투명 실선 · **예상과 같은 굵기**(6px) | 굵기로 위계를 주면 값 비교가 왜곡됨 |
| 네모 테두리 | **전량 폐기** | 운영자 1차 지시 |
| Y축 중략 | 물결 2줄 + y축 물결 · 아래 구간 66% / 갭 7% / 위 27% | 축 중략 표준 문법 |
| 중략 임계 | `autoBreak()` 자동 계산 (고정값 금지) | 라인업이 매년 바뀌므로 고정하면 재발 |

## 3. 조사 근거 (3차 실사례 — 9종 수렴)

- **IBCS / ISO 20707** — 실적=solid · 계획=outline · **예상=hatched**. 국제 비즈니스 보고 표준.
- **Stephanie Evergreen «Four Ways to Show Projections»** — ①점선 ②페이드 ③회색화 ④범위.
  본인은 **패턴필 비추천 · 페이드 1순위**. ← 채택 근거
- **Peltier Tech / StatCan** — 실선=실적, 점선=예상 + 전환 지점 경계 표시.
- **Bootstrap · Chakra progress** — 미충족 구간 = 45° 줄무늬.
- **bullet chart (Stephen Few)** — 목표는 채우지 말고 마커 1개.
- **Highcharts** — rgba 반투명 채움 + borderDashStyle.

시안 9종 렌더 = `260805_예정게이지_시안9_실사례.png` (생성기 = 같은 이름 `.html`)

## 6. 남은 리스크

- 물결 갭이 막대를 가로지를 때 **막대 색이 갭 배경색으로 지워진다** — 배경이 단색이 아닌
  표면(그라데이션 카드 등)에 이식하면 갭이 티 난다. 그 경우 `<mask>`로 전환 필요.
- `autoBreak()`의 거인 판정 = 「중앙값의 4배 초과」 · 「거인이 전체의 25% 이하」.
  실데이터로 한 번 검증 필요(현재는 스크린샷 근사값으로만 확인).
