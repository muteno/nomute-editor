260805 이미지 스튜디오 「깨진 화면 3.2초」 전/후 + 셸 부팅 지연 진단

운영자 지시 — 「지금 일단 화면을 열때, 굉장히 로딩이 느려졌어. 문제 확실히 잡아주고, 이미지 스튜디오 열때, 첨부1의 화면이 나왔다가 지연된 다음 정상 출력이되는데 코드 뜯어서 확인 좀 해줘.」
계측 = 헤드리스 크로미엄 CDP 스크린캐스트 · 폰 실조건(430×932 · 4G 1.6Mbps/90ms RTT · CPU 4배 스로틀) · 라이브 코드 무접촉(페이지 전역 openTool만 호출).

나머지 절반은 어디까지 파싱됐느냐다. thumb.html(663KB)은 마크업이 27.8~35.1% 구간이고 나머지 65%가 인라인 <script> 430KB — 도크·폼을 그 스크립트가 만든다. 마크업만 파싱된 순간 노출되니 도크·입력폼 없이 결과(0)·이전 제작(0) 뼈대만 뜬다.

왜 지금 터졌나 — frEarly(260725 「일단 틀 띄워놓고」)의 주석은 정본을 「readyState가 loading을 벗어나는 순간 = DOMContentLoaded = 인라인 스크립트까지 실행 완료 = 틀 완성」이라 선언해 놓았는데, 실제 조건은 그보다 앞선 「뭐라도 그려졌으면 통과」였다. 선언과 구현이 갈라진 자리에 thumb.html처럼 틀을 스크립트가 만드는 문서가 들어오면서 드러난 것.

② 처방 — 노출 전에 주입한다 + 틀이 완성될 때까지 3초 기다린다

변경내용
