영상 스튜디오 제작 과정 통일

제작 흐름 = 이미지 스튜디오(카드 생성) 정본 그대로: 발사 게이지 → 생성 중 알약 → •결과 잡 행 → 완료 카드. 현행 실측 = k·vd 잡 행 이미 정본 · edit만 버튼 로더 단독 · song 자체 상태줄. 갤러리에서 방식·단계·길이 배지를 고르고 → [제안] 복사값만 회신하면 그 턴에 edit·song 배선까지 간다. 영상 고유 정보(%·남은 시간·길이)는 기존 슬롯(잡 행 상태·캡션 알약)에만 싣는다 = 부품 신설 0 · 미리보기 좌상단 배지 신설 없음.
