증상 재현 조건

직전 제작 결과가 화면에 남아 있는 상태에서 새 영상을 첨부하면, 넣은 영상이 화면에서 통째로 사라진다.
첫 첨부(결과 없음)만 정상이라 상비 스모크의 fresh 경로가 잡지 못했다 — 2회차 첨부부터 항상 재발.

전후 — 결과가 떠 있는 상태에서 새 영상 첨부

BEFORE — 넣은 영상이 안 보임

첨부 직후 실측: .pvsec 높이 0px · opacity 0 · topDock.fold = true → 넣은 영상이 화면에 0px

AFTER — 넣은 영상이 바로 보임

첨부 직후 실측: .pvsec 높이 261px · opacity 1 · topDock.fold = false → 첨부한 영상 즉시 표시

바뀌지 않은 것 — 260728 도크 자동 접힘 계약
