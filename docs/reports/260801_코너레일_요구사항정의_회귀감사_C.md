## ① 요구사항 정의서

### 배경 (근거 = thumb.html 468~495행 주석 이력 + 시안 §⑤)
1. 편집 도크 2분할(운영자 260730 "좌 미리보기 / 우 옵션 세로") 이후, **우측 옵션 컬럼(`#editCol`)이 비는 탭(카드 생성·AI 생성·특수)에서 예약폭(`--optw` 8.8em+gap)만 먹었다** → 260801 `:has(> .dockopt.none)` 폭 회수 = 미리보기 전폭(thumb:472).
2. 전폭이 되자 비율 계약을 재정의 — **창 = 폭 기준 1:1 고정비**(thumb:480 `aspect-ratio:1/1` · "운영자 260801 플레이그라운드 선택값" 주석 실존) · max-height 캡 폐지(구 캡이 높이만 눌러 비율을 깨던 사고).
3. 남은 문제 = **그럼 옵션(비율·해상도·보존·모자이크)을 어디에 두나** → 시안 정본이 답: 미리보기 창 **코너 세로 레일**에 SNS 네비(`.trail`) 문법 그대로 얹는다(시안 h1 "SNS 네비(.trail) 문법 그대로").

### 문제 정의 (근거 = 시안 .sub + thumb 이력)
- 하단 옵션바/우측 컬럼은 **미리보기와 시선이 분리**된다 — 운영자 원문 "우측에 네비게이션을 두고 미리보기 사진 하단의 옵션바를 삭제하는 방법을 택했다".
- 편집 탭 전용 우측 컬럼(`#editCol`)은 다른 탭에서 낭비(위 배경 1) — 코너 레일은 창 안에 있으므로 탭 무관 동일 문법.

### 목표 상태 (근거 = 시안 railHTML() 345행 주석 "위쪽에 교체·삭제 + 구분선 + 아래에 옵션값")
- 미리보기 창 코너 세로 레일 = **[교체·삭제 픽토 묶음 `.trail-g`(gap 2px 밀착 = `.trail-rg` 「한국｜세계」 차용)] → `.trail-div`(정본 헤어라인 14×1) → [값 칩: 비율·해상도·모자이크·보존]**.

### 크로스파일 정합 (thumb = iframe 문서, index `.trail` CSS 상속 불가)
- **공유 메커니즘 실측**: `viewer/tokens.css`는 **구조 토큰만**의 거울(tokens.css 헤더 주석 · `build_design_mirror.py` `_STRUCT_PREFIX`) — **컴포넌트 CSS는 거울 불가**가 명문(check_refs.py:1541 "tokens.css = 구조토큰 거울·컴포넌트 불가"). 따라서 코너 레일은 thumb에 **CSS 사본**으로 갈 수밖에 없다(= CII 90행 「합성 미리보기 쉘」의 크로스-파일 이식 선례와 동축).
- **드리프트 차단 게이트 부재 → 신설 제안**: `_LAUNCH_BTNS` 방식의 레지스트리 게이트(예 `_TRAIL_SPEC` = 캡슐 border rgba(255,255,255,.14)·bg rgba(8,15,11,…)·blur var(--blur-s)·radius var(--r-pill) 4속성 동결, index+thumb 등재)를 check_refs에 추가 — 사본이 정본과 어긋나는 순간 커밋 차단.
- **툴톤 갈라짐(CII 90행 함정① 재발 축)**: `.trail-i`는 `var(--mut)` 소비 — thumb `--mut`은 툴톤(팔레트 핀 게이트의 `_PALETTE_TONE` 제외 집합)이라 index와 값이 다르다. 캡슐 리터럴은 동일하나 **칩 글자색이 표면마다 갈라짐** — 의도 여부 운영자 판정 필요(정본 리터럴 고정 vs 툴톤 수용).
- CII 등재 현황: `.trail` = 56행 「책갈피 점프 레일」 실존 · 「합성 미리보기 쉘」 = 90행 실존. **「코너 옵션 레일」 행은 없음 → 신규 행 등재 필요**(계승 부모 = 56행 + 90행 `.cpv-tool` 열 갱신 · 검증 열 = 신설 게이트).
