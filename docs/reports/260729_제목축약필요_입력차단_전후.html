이미지 제작 — '축약필요'가 뜬 행은 더 이상 글자가 안 들어감

260729 · 대상 = 이미지 스튜디오 /2 제작 헤더(부제·제목)·자막, /1 포스트 텍스트 · 판정기 = 기존 estHeaderTr/estTracking(빨강 힌트와 동일 계산기) 재사용 · 아래 칸은 실제로 타이핑되는 재현(실물 로직 미러)

1. 제목 행 — 전 / 후

BEFORE — 종전경고만 뜨고 계속 입력

헤더 노뮤트

→ 빨강 '축약필요'가 떠도 글자는 계속 들어감. 발사 시점에 게이트가 막아 되돌아와 다시 지워야 했다.

AFTER — 이번 변경그 행에서 입력 정지

헤더 노뮤트

→ '축약필요'가 뜨는 그 글자까지는 들어가고(안내가 먼저 보여야 함), 그 다음 글자·붙여넣기가 막힌다. 지우기는 그대로.

※ 이 재현칸의 폭 계산 = 실물 estHeaderTr(제목 fs 90 · 가용폭 960 · 자간 0→−45) 미러. 실물은 Pretendard 실측폭이라 임계 글자수가 ±1 다를 수 있다.

2. 자막(여러 줄) — '그 행'만 막힌다

오버레이 릴스
  • 초과한 줄 = 그 줄만 추가 입력 차단
  • 엔터(개행) = 안 막음 → 다음 줄로 넘어가서 계속 쓸 수 있다
  • 다른 줄 = 영향 없음(캐럿이 놓인 줄만 판정)

4. 안전장치

  • 지우기·수정은 항상 허용 — 초과분을 줄일 길을 막으면 칸이 잠긴다
  • 프로그램 주입은 비대상(isTrusted 게이트) — 임시저장 복원·축약 적용·맞춤법 교정본이 잘려나가지 않는다
  • 한글 조합(IME) — beforeinput이 취소 불가한 경로라 조합 확정 시 되돌림(compositionend)
  • 새 UI·새 한도 0 — 표시는 기존 빨강 '축약필요' 힌트 그대로, 발사 게이트도 그대로
