# 코너 레일 펼침 팝 — 글래스 + 펼침 효과 10안 (260801)

> 운영자 260801 「버튼 눌렀을때 나오는 토글 글래스모피즘 적용한거로 기존 디자인 기틀 있어 · 10개정도 제안 · 펼쳤을때 효과까지 있어야」.
> **제안서다. 고르면 그 안으로 플레이그라운드(8요소)를 뽑아 만져보게 한다.**

---

## 0. 기존 기틀 실측 — 새로 만들 게 아니라 이걸 쓴다

**앵커 팝업 셸 SSOT** (`viewer/index.html:220` · 운영자 260706 "필터 창을 메인으로 · 앞으로 만들 내부 팝업 다 동일")
```
.pmenu, .filterpop, .pubpop, #linkpop, .sc-rsn, .min-pick, .failmenu {
  background: var(--modal-glass-anchor);                    /* rgba(17,18,20,.42) */
  backdrop-filter: blur(24px) saturate(var(--anchor-sat,1.05));
  border: 1px solid rgba(255,255,255,.14);
  box-shadow: 0 24px 56px rgba(0,0,0,.55), inset 0 1px 0 rgba(255,255,255,.08);
}
```
> **새 앵커 팝업 = 이 셀렉터에 클래스만 추가하면 자동 통일**이라고 정본 주석이 못박아 뒀다. 즉 **코너 레일 펼침 팝의 정답 1순위는 「셀렉터에 합류」**이고, 아래 10안은 *그 위에서 무엇을 더/덜 할지*의 선택지다.

**펼침 애니 정본 3종**
| 이름 | 값 | 쓰임 |
|---|---|---|
| `popIn` / `popOut` | `scale(.92) translateY(-4px)` ↔ `none` · `--dur .18s` | 아바타 메뉴(`.pmenu`)·필터창 — **절제형** |
| `msgUnfold` | `scale(.82) translateY(-8px)` → `none` · `.26s cubic-bezier(.22,.61,.36,1)` | 메시지함·발행본 — **촤르륵 펼침** |
| `msgUnfoldUp` | `scale(.82) translateY(10px)` → `none` | 아래 앵커(위로 펼침) 미러 |

**transform-origin 관례** = `.pubpop{transform-origin:top right}` · `.anch-b{bottom center}` — **누른 지점에서 자라나는** 문법이 이미 있다.

**닫힘 = 역재생** (`popOut` = "아바타로 촤르륵 접힘") · `prefers-reduced-motion` 가드 전건 필수.

---

## 1안 — 셀렉터 합류(무개조) ★기본값
`.opt-pop`을 `.pmenu, .filterpop, …` 그룹에 **클래스만 추가**. 애니 = `popIn`(.18s).
- **장점**: 값 창작 0 · 팝업 톤이 앱 전체와 자동 동기(그룹 값 바뀌면 같이 바뀜) · 리스크 최저.
- **단점**: 레일이 *작은* 컨트롤인데 팝은 *큰* 팝업 톤(blur24·shadow 56px) — 과할 수 있다.
- 판정 = 먼저 이걸 보고, 과하면 2·3안으로.

## 2안 — 셀렉터 합류 + 촤르륵(`msgUnfold`)
셸은 1안 그대로, 애니만 `.26s msgUnfold`(scale .82 → 1)로.
- 「펼쳤을 때 효과」 요구에 가장 직접적. `transform-origin`을 **누른 칩 방향**으로 잡으면 칩에서 튀어나온다.
- 단점: 작은 팝에 .26s는 굼떠 보일 수 있다(→ 3안).

## 3안 — 셸 합류 + 레일 스케일 축소 변주
셸은 그룹 계승하되 **코너 스코프에서만** `blur(24px)→var(--blur-l) 22px`·`shadow 24/56→12/28`로 반 단계 낮춤. 애니 = `popIn`.
- 레일 캡슐(`.trail` blur 8 · 알파 .34/.54)과 팝 사이 **점프를 줄인다**. 지금은 8 → 24로 3배 튄다.
- ⚠ 그룹 이탈 = 역제안 대상(적용 범위 = 코너 한정).

## 4안 — 캡슐 연속체(레일과 팝이 한 몸)
팝의 배경·블러·테두리를 **`.trail` 캡슐 값 그대로**(`rgba(8,15,11,α)` · blur 8 · border .14) 쓰고, 라운드만 `--r-l`.
- 「레일이 길어졌다」는 감각 — 별개 팝업이 아니라 **같은 캡슐의 확장**.
- 애니 = 높이만 자라는 `clip-path`/`grid-rows 0fr→1fr`(아코디언 정본 `--dur-acc .26s` 계승).
- 단점: 앵커 팝업 SSOT 이탈(그룹 톤과 갈라짐).

## 5안 — 아코디언 인라인(팝 자체를 없앰)
팝업을 띄우지 않고 **레일 안에서 그 항목만 세로로 펼친다**(선택지가 칩 아래로 흘러나옴). 정본 = `.geni-camsub`/`.cfoldsub`의 `grid-template-rows:0fr→1fr` + 체브론 회전.
- **장점**: 레이어 0개 · 겹침·클램프 문제 소멸 · 이미 있는 접이 문법 100% 재사용.
- **단점**: 레일이 길어져 세로 공간을 먹는다(9:16 스테이지에선 부담).

## 6안 — 스태거 등장(항목이 차례로)
셸 = 1안. 팝 안 **버튼들이 40~50ms 간격으로 순차 등장**(`animation-delay: calc(var(--i)*45ms)`).
- 정본 있음 = 대기열 행(`.qpop .qlist .qrow`) 스태거. `prefers-reduced-motion`에서 일괄 off.
- 선택지가 5개(비율)일 때 "펼쳐진다"는 감각이 가장 강하다.

## 7안 — 현재값에서 자라기(origin = 눌린 칩)
`transform-origin`을 **눌린 칩의 실좌표**로 매 회 계산해 넣는다(JS 1줄). 애니 = `msgUnfold`.
- 지금 시안은 origin이 코너 고정이라 팝이 *코너에서* 튀어나온다. 칩 기준으로 바꾸면 **누른 그 자리에서** 자란다.
- 정본 = `placePopNearMenu`(운영자 260707 "열린 메뉴 가까이")와 같은 축.

## 8안 — 선택칩 자리바꿈(모프)
팝이 열릴 때 **현재값 칩이 팝 안 같은 값 위치로 이동**하는 것처럼 보이게(현재값 칩 opacity 0 + 팝의 해당 항목이 그 좌표에서 시작).
- 가장 "고급스러운" 축. 값이 어디서 왔는지 시선이 안 끊긴다.
- ⚠ 구현 난도 최상 · 리듀스드모션·빠른 연타 시 깨지기 쉬움. **먼저 6·7안으로 충분한지 보는 게 낫다.**

## 9안 — 레일이 뒤로 물러남(depth)
팝이 열리는 동안 레일 캡슐이 `scale(.96)` + `opacity .6`으로 살짝 후퇴.
- 팝이 트리거를 덮는 문제(지금 우상단 origin에서 실제로 발생)를 **의도된 연출로 전환**.
- 정본 = 눌림 `--press-*` 사다리 값 재사용(신규 값 0).

## 10안 — 딤 없는 라이트 디스미스 + 바깥 탭 접힘
백드롭 딤을 두지 않고(미리보기를 가리지 않음), 바깥 탭/스크롤 시 `popOut` 역재생으로 접힘.
- 정본 = `.pmenu.closing{animation:popOut}` + `closeOverlays` 패턴.
- 「효과」의 절반은 **닫힐 때**다. 지금 시안은 즉시 사라져서 싸구려로 보인다.

## 조합 권장

이 10개는 **배타적이지 않다**. 실제로는 3층으로 고르면 된다.

| 층 | 후보 | 추천 |
|---|---|---|
| **셸(톤)** | 1 · 3 · 4 | **1안**(무개조 합류)으로 먼저 보고, 튀면 3안 |
| **펼침** | 2 · 5 · 6 · 7 · 8 | **7 + 6**(눌린 칩에서 자라며 항목 스태거) |
| **닫힘·주변** | 9 · 10 | **10안 필수**(닫힘 역재생) · 9안은 취향 |

**최소 세트 = 1 + 7 + 6 + 10** — 전부 정본 계승이라 **신규 값 0**이고, 「펼쳤을 때 효과」 요구를 채운다.
