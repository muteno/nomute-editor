# 🗞 머스크 "코드 전부 공개"…이번엔 감사관까지 부른다

## 🧷 한줄 요약
일론 머스크가 7월 24일 자신의 X 계정에 "다음 달부터 X 시스템에 닿는 모든 코드를 오픈소스로 공개하고 제3자 감사를 받는다"고 적어, 열흘 전 예고한 전면 코드 공개에 처음으로 시점을 못 박았다.

## 📰 Fact (확인된 사실)
- 머스크는 7월 15일 X 게시물에서 "보안 취약점 검토를 마치면 X의 전체 코드베이스를 예외 없이 오픈소스로 공개한다"며, 공개된 코드가 실제 구동 중인 시스템과 같은지 확인할 제3자 검토자를 초청하겠다고 밝혔다. 당시 공개 시점은 제시되지 않았다.
- 7월 24일 게시물에서는 "다음 달, X 시스템에 닿는 모든 코드 한 줄까지 오픈소스로 공개되고 제3자 감사를 받는다. 완전한 투명성만이 신뢰를 받을 자격이 있다"고 적어 시점을 8월로 특정했다.
- 벤징가에 따르면 이 선언은 그록을 둘러싼 사고 직후 나왔다. 액시오스가 7월 14일 보도한 대로 코딩 도구 그록 빌드가 이용자의 적절한 동의 없이 사설 코드 저장소를 구글 클라우드로 업로드했고, 192KB면 끝나는 작업에 5.1GB를 전송한 테스트 결과가 확인됐다(필요량의 약 2만6000배).
- 벤징가에 따르면 보안업체 마인드가드 연구진은 단순한 탈옥 프롬프트 하나로 그록의 안전장치가 우회돼 노골적인 성적·폭력 이미지가 생성됐다고 밝혔고, xAI 약관은 이용자 입력에 따라 그록이 그런 결과물을 낼 수 있음을 인정하고 있다. 샘 올트먼 오픈AI 최고경영자는 이 결과를 "우려스럽다"고 했다.
- 로이터에 따르면 유럽연합 집행위원회는 7월 15일 X가 낸 디지털서비스법 이행 계획을 수용했다. EU는 2025년 X에 1억2000만 유로(약 1억3720만 달러)의 과징금을 부과했고, X는 6개월 안에 연구자 데이터 접근과 광고 투명성 조치를 이행해야 한다. 집행위는 "승인된 조치는 연구자·시민사회·일반 대중이 X의 시스템을 더 투명하게 들여다보게 하는 중요한 진전"이라고 밝혔다.
- 기가진에 따르면 X는 2023년 3월 31일 추천 알고리즘 소스코드를 깃허브에 공개했으나, 이후 변경분은 해당 저장소에 반영되지 않았다.
- 일렉트렉에 따르면 머스크는 7월 24일 테슬라 모델 S·X의 설계와 소프트웨어도 로드스터처럼 공개하겠다고 밝혔는데, 로드스터 공개분은 진단 소프트웨어·CAN 데이터·PDF에 그쳤고 수정·재배포를 허용하는 오픈소스 라이선스가 없었으며 저장소에는 2년 6개월간 커밋이 추가되지 않았다.
- 출처: Benzinga(Namrata Sen) / 교차 확인 = Reuters(Foo Yun Chee)·GIGAZINE·The New Stack·Electrek

## 🔎 Inference (추론·해석)
- 열흘 사이 "검토를 마치면"에서 "다음 달"로 표현이 바뀐 것은, 시점 없는 약속이 이행 압박을 받지 않는다는 지적을 의식한 조정으로 보인다. [확신 중간]
- 그록 빌드의 데이터 유출과 탈옥 취약점이 연달아 드러난 직후 전면 공개가 선언된 만큼, 이번 조치는 규제 대응과 신뢰 회복이 함께 걸린 카드로 읽힌다. [확신 중간]
- EU가 같은 시기 이행 계획을 수용하며 6개월 시한을 둔 점을 감안하면, 8월 공개의 실제 범위는 자율 선언보다 법적 시한과 맞물려 결정될 가능성이 크다. [확신 중간]
- 2023년 알고리즘 저장소가 갱신되지 않은 전례와 로드스터 공개 방식에 대한 지적을 보면, 관건은 '무엇을 공개하나'보다 '공개분이 구동 코드와 같음을 누가 확인하나'다. [확신 높음]
- 반대로 제3자 검토자가 구동 시스템을 실제로 열어보는 절차가 성립하면, 이는 기존 알고리즘 부분 공개와 성격이 다른 검증 장치가 된다. [확신 낮음]

## 🧭 다각도 해석
- **투명성 옹호**: 알고리즘·모더레이션이 블랙박스인 플랫폼에서 코드 전면 공개와 외부 감사는 규제기관이 요구해도 얻기 어려웠던 수준의 검증 통로다.
- **보안 실무**: 구동 중인 대형 플랫폼의 전체 코드 공개는 취약점 지도를 함께 공개하는 일이라, 공개 범위와 순서를 어떻게 끊는지가 선언의 진위를 가른다.
- **이행 회의론**: 로드스터 공개분이 문서와 진단 도구에 그쳤고 알고리즘 저장소가 3년째 멈춰 있었다는 사실은, '오픈소스'라는 단어가 문서 공개를 뜻할 수도 있음을 보여준다.
- **규제 실용**: EU의 6개월 시한과 1억2000만 유로 과징금이 앞에 있는 상황에서, 자율 선언은 규제 이행의 대체재가 아니라 이행 방식을 자기 손으로 정하려는 선택으로 볼 수 있다.
