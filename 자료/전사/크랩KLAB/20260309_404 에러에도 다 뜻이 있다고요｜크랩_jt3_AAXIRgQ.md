인터넷에 오류 떴을 때 흔히 볼 수 있는 404 코드 우리나라뿐만 아니라 전 세계적으로 활용되는 숫자라서요. 각종 밈으로
심지어 노래 제목으로까지 활용되고 있는데요. 그런데 이 숫자 정확하게 무슨 뜻인지 알고 계신가요.
404 에러 코드는 사각 터져서 부르는 숫자를 의미하는 게 아니라 http 상태 코드 중 하나인데요. 쉽게 말하면 크롬이나 사파리 같은 브라우저에서
서버로 이 주소의 페이지를 보여주세요 하고 요청했을 때 요청 결과를 딱 요약해서 알려주는 신호인 거죠.
웹 초창기 HTTP가 처음 만들어졌을 땐 지금처럼 숫자로 된 상태 코드는 없었다고 해요.
요청을 실패하면 그냥 텍스트로 설명을 보내거나 연결을 끊어버리는 시기였죠.
그런데 1996년 HTTP 1.0이 표준화되면서 지금 우리가 아는 세 글자의 상태 코드가 공식적으로 도입됩니다.
성공했는지 잘못됐는지 아니면 서버가 지금 서비를 설 수 없는지 같은 것을
컴퓨터가 자동으로 처리할 수 있게 만든 표준 규칙이라고 보시면 됩니다.
특히 세 자릿수 중에 앞자리에 특별한 의미를 둬서요.
첫 숫자만 봐도 지금 대충 어떤 상황인지 한눈에 알 수 있게 했는데요.
1이면 정보를 받았고 작업을 진행 중이라는 뜻이고요.
2는 작업 성공, 3은 리디렉션이라고 해서 다른 곳으로 가주세요 하는 응답이고요.
4는 이용자의 브라우저에 문제가 있는데 하는 신호
5는 응답을 줘야 하는 저쪽 서버에 뭔가 문제가 있다는 뜻입니다. 그리고 앞글자 뒤에 붙는 숫자 2개는 상세 내용을 의미하는데요.
04는 해당 웹사이트를 못 찾겠다. 즉 브라우저 쪽에서 준 주소 자체에 문제가 있어서 해당 사이트를 못 찾겠다라는 응답이라고 보시면 되겠죠.
404 코드는 사용자의 실수로 빈번히 보이는 상태 코드라서요. 나름 해결 방법도 간단하다고 해요.
오타가 제일 많고요. 오타인지 확인하는 게 제일 문제일 거고 또 다른 경우에는 해당 사이트가 이동했다든지 하는 경우가 있거든요.
검색을 해가지고 이동한 사이트를 찾는 게 좋을 것 같고
경우에 따라서는 캐시에 내용이 남아가지고 엉뚱하게 나오는 경우가 있어서
새로 고침하는 게 제일 쉬운 방법이라고 생각합니다.
4로 시작하는 상태 코드는 요청한 쪽의 실수나 오류로 인해 나타나는 숫자라서
404 외에도 403, 401 등 다양하게 나타납니다.
인증이 필요한 경우, 로그인 같은 게 필요한 경우는 401로 대답이 오고
403도 주로 보실 수 있는데 권한이 없어가지고 접근을 못하는 경우에
403, 4B 등 이런 식으로 대답이 오고요.
429도 있습니다.
너무 요청을 많이 해서 속도 제한이 걸린 경우에 투맨이 리퀘스트를 응답이 오는 경우가 있습니다.
자로 시작하는 것 외에 또 흔하게 볼 수 있는 상태 코드는 바로 숫자 5로 시작하는 500 502 등이 있는데요.
5로 시작하는 건 우리에게 정보를 보내주는 서버에 문제가 있다는 거라서요.
과부하가 되거나 서버끼리 통신하다가 문제가 생기면 나타난 숫자이기 때문에 우리에게 익숙할 수밖에 없고요.
이 경우 사용자 입장에서 해결할 수 있는 게 딱히 없다고 해요. 일반적으로는 일시적인 통신 오류 그런 경우이기 때문에
브라우저에서 새로 고침을 하든지 아니면 조금 이따 재접속하는 게 제일 쉽고요.
실제로 서버 쪽에 문제가 있는 경우에는 서버 관리자한테 요청하는 방법밖에 없습니다.
그 외에 1로 시작하는 숫자는 처리 중, 2로 시작하는 숫자는 성공이라는 뜻으로 웹사이트에서 보기 어렵고요.
앞자리 3번은 리디렉션, 그러니까 다른 데로 가주세요 하는 의미이지만
이게 사용자에게 직접 가주세요라고 요청하는 게 아니라 서버가 직접 움직이는 경우가 많다고 해요.
볼 수 있는 게 대부분 4번 아니면 5번밖에 없습니다.
한 번은 사실 웹브라우저에서는 못 볼 거고요. 실제로 어디로 이동해야 되는지 아는 경우로 서버가 아는 거고요. 그래서 웹브라우저가 자기압 받아서 우리한테는 그냥 이동된 사이트로 보여주겠죠.
이 모든 코드는 국제인터넷표준화기구에서 정의하고 인터넷 주소자원 총괄관리기관인 IANA에서 관리하는데요.
두 기관에서 표준적으로 사용되는 코드를 안내하고 있으니 컴퓨터 하다 가끔 모르는 번호가 뜨면 여기서 확인해보시면 될 것 같고요.
여러분이 가장 자주 본 상대 코드가 있다면 댓글로 공유해주세요.
앞으로 404 보면 당황하지 말고 오타 먼저 확인해야겠다.
