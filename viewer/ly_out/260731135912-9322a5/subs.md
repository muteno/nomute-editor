# 로봇청소기를 지키지 못했습니다

## ⓪ 개요
- **내용**: 로봇청소기를 지키지 못했다는 자책 섞인 고백 — 지금은 원격으로 상태를 확인 중이라는 상황 설명.
- **화자**: 1인(본인 상황 설명)
- **메타**: 0:13 · 한국어 · 한국어 원본 모드 · 조각 4개

「원본 구절 수: 4개 → 자막 조각 수: 4개」
⚠ 뭉개짐 의심 3조각 — 상세 편집기에서 그 조각만 고쳐 '다시 입히기'하면 해당 부분만 재생성
