# 🗂 디자인기틀 폴더 — 진입점 (운영자 260725 "정본 한 폴더에 다 모아줘")

> **디자인 볼 땐 이 폴더 하나.** 여기저기(`docs/`·`구성도/`) 흩어져 있던 디자인 기틀 **문서 정본을 전부 이 폴더로 물리 이동**했다(260725). 다만 정본 중 **코드·데이터로 살아 있는 것**(값 `:root`·게이트·훅·거울)은 옮기면 라이브 웹앱·기계 게이트가 끊어져 **원위치가 정본** — 대신 아래 §2가 전량 지목한다(경로 클릭 = 바로 열림).
>
> ⚠️ **규칙·값의 단일 진입점은 여전히 「규칙2번」 [`디자인기틀_SSOT.md`](디자인기틀_SSOT.md)** — 이 파일은 *폴더 안내판*이지 규칙 정본이 아니다(둘 다 규칙을 담으면 드리프트). 무엇을 지키나 = SSOT §0 · 얼마인가 = `viewer/index.html :root`.

## 3. 유지 규칙

1. **새 디자인 기틀 *문서*가 생기면 이 폴더에 만든다**(`docs/`에 만들지 말 것) + [`디자인기틀_SSOT.md`](디자인기틀_SSOT.md)에 행 추가(누락 = 규칙2 위반).
2. **§2의 코드 정본을 이 폴더로 복사하지 마라** — 사본 금지, 포인터만(값·규칙 실체 복붙 = 드리프트원 = SSOT 서문·유지규칙 2).
3. 폴더 이동으로 **정본의 위계는 바뀌지 않았다** — 충돌 시 언제나 `viewer/index.html :root`가 최종 정본.
